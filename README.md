# 🔍 Duplicate & Similar Data Finder - `duplicate_similar_finder_pd`

This project helps detect near-duplicate entries in datasets using **Pandas** 🐼 and **FuzzyWuzzy** 🔍.  
Ideal for cleaning CRM systems, product catalogs, and user-generated datasets.

## 🚀 Features
- Upload any CSV file 📁
- Auto-detects and compares entries from a selected column 🧠
- Adjustable similarity threshold via slider 🎚️
- Interactive UI powered by **Streamlit** 🎨

## 🧪 Tech Stack
- `pandas`
- `fuzzywuzzy`
- `streamlit`

## ▶️ How to Run

```bash
pip install pandas fuzzywuzzy streamlit python-Levenshtein
streamlit run app.py
```
